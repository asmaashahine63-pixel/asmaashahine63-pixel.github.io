LIGHT WEBSITE PACKAGE — 55 kW Wind Turbine Gearbox

1. Extract this ZIP on your computer. DO NOT upload ZIP as a single website asset.
2. Open your GitHub Pages repository at root.
3. Upload the projects/, assets/, and pdf/ folders while preserving their subfolders.
4. Commit directly to main.
5. In the LIVE root index.html replace the existing gearbox project card with the content of HOMEPAGE_CARD_TO_ADD.html. Avoid duplicate cards.
6. Verify GitHub Actions -> Pages deployment and hard refresh the homepage.

This package intentionally excludes large native CAD ZIP files and the original WMV. The MP4 is included.
