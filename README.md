# Asmaa Shahine — Aerospace Engineering Portfolio

Static, responsive GitHub Pages portfolio. Original site implementation informed by the general multi-project layout of a reference portfolio; no third-party code, pictures or documents are reproduced.

## Publishing
Upload all contents of this folder into the root of `asmaashahine63-pixel.github.io` (the `main` branch). Ensure **Settings > Pages > Deploy from a branch > main / (root)**.

## Adding real project media
Add your own images to `assets/` or another folder and link them from the relevant page. Replace placeholder documentation paragraphs only with verified project material.

## Contents
- `index.html`: homepage
- `assets/style.css`: responsive design
- `projects/*.html`: eight project pages
- `pdf/Asmaa_Shahine_CV.pdf`: uploaded CV

Review the CV and project descriptions before publication, including any dates and technical figures.
