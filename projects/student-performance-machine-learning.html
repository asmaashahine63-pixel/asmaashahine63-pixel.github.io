Student Performance Prediction

Exploratory data analysis, regression and classification on 20,000 student records

This project investigates how academic history, study habits, personal circumstances and course characteristics relate to student outcomes. Working with a 20,000-record, 41-column dataset, the team implemented cleaning, outlier handling, encoding, feature scaling, numerical final-score prediction, multiclass final-grade classification and binary pass/fail prediction. The page presents the original experiment results and model comparisons alongside an evaluation of their limitations.

TECHNICAL LIMITATIONS

Model interpretation and safeguards

The dataset includes final_score, final_grade and pass_fail, which are closely linked student outcomes. Any experiment predicting one while using the others as input risks information leakage. The notebook's full-dataset scaling and imputation order should also be checked against train/test splits. For trustworthy generalization claims, preprocessing and SMOTE should be fit inside each training fold, and target-derived predictors should be excluded.

The original notebook is retained unaltered. This page reports its metrics faithfully while distinguishing those numbers from independently verified, leakage-safe performance.
