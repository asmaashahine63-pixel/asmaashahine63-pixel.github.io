Project brief

Aircraft pitch describes rotation about the lateral body axis. Using a simplified small-disturbance longitudinal model, the project derives a pitch-angle transfer function from elevator deflection and investigates how controller design affects tracking, overshoot and settling. It compares the unregulated plant, feedback settings tested in Simulink and a subsequently tuned PID response.

The report states the following transfer function:

P(s) = θ(s)/δ(s) = (1.151s + 0.1774) / (s³ + 0.739s² + 0.921s)

The characteristic polynomial includes a pole at s = 0; therefore, the open-loop plant should not be described as asymptotically stable. The unbounded response visible in the report is consistent with the integrator in the model. The page retains the report's original figure sequence while flagging this interpretation.

Engineering assessment and limitations

  • Open-loop: the pitch plant contains an integrator, and the report's open-loop step response does not settle in the displayed interval. This is more precise than the report's unqualified statement that the system is stable.
  • Feedback gain variation: higher forward-path gain does not consistently improve the plotted responses; several traces show substantial overshoot or oscillation.
  • PID tuning: the tuner screenshot and final response show improved tracking. The report states overshoot below 5% and settling within 2–3 s, but these are reported metrics, not independently recomputed values.
  • Reproducibility: the original three Simulink .slx models are included. No .m script was supplied; models are not claimed to have been executed or verified in MATLAB.
